# Glosario y checklist de calidad

Referencia rápida transversal para esta skill: no desarrolla ningún framework
(eso está en los demás archivos de `references/`), solo fija terminología y
sirve de control de calidad final antes de entregar un informe.

## Glosario bilingüe (ES/EN)

| Sigla | Español | Inglés | Qué es |
|---|---|---|---|
| VUCA | Volátil, Incierto, Complejo, Ambiguo | Volatile, Uncertain, Complex, Ambiguous | Marco para describir un entorno externo inestable y difícil de predecir. |
| BANI | Frágil, Ansioso, No lineal, Incomprensible | Brittle, Anxious, Non-linear, Incomprehensible | Marco que sustituye a VUCA para describir dinámicas internas/sociales de ruptura en vez de solo volatilidad externa. |
| DAFO / FODA | Debilidades, Amenazas, Fortalezas, Oportunidades | SWOT — Strengths, Weaknesses, Opportunities, Threats | Análisis 2x2 de factores internos (fortalezas/debilidades) y externos (oportunidades/amenazas). |
| PESTEL / PEST | Político, Económico, Social, Tecnológico, Ecológico, Legal | Political, Economic, Social, Technological, Environmental, Legal | Análisis del entorno macro externo que afecta a un negocio o sector. |
| BMC | Modelo de Negocio Canvas | Business Model Canvas | Lienzo de 9 bloques para diseñar o validar cómo una organización crea, entrega y captura valor. |
| Ansoff | Matriz de Ansoff | Ansoff Matrix | Cruce de producto (actual/nuevo) y mercado (actual/nuevo) para mapear opciones de crecimiento: penetración, desarrollo de producto, desarrollo de mercado, diversificación. |
| 7S | Las 7S de McKinsey | McKinsey 7S Framework | Marco de diagnóstico organizativo sobre 7 elementos internos interdependientes (estrategia, estructura, sistemas, valores compartidos, habilidades, estilo, personal). |
| SMART | Específico, Medible, Alcanzable, Relevante, Temporal | Specific, Measurable, Achievable, Relevant, Time-bound | Criterios para formular objetivos bien definidos y accionables. |
| OKR | Objetivos y Resultados Clave | Objectives and Key Results | Sistema para desplegar objetivos en el tiempo mediante resultados clave medibles y trimestrales. |
| RACI | Responsable, Aprobador, Consultado, Informado | Responsible, Accountable, Consulted, Informed | Matriz para asignar roles y responsabilidades en un proceso o decisión. |
| VRIO | Valor, Rareza, Imitabilidad, Organización | Value, Rarity, Imitability, Organization | Secuencia de preguntas para evaluar si un recurso o capacidad interna es fuente de ventaja competitiva sostenible. |
| BCG | Matriz BCG (Boston Consulting Group) | BCG Matrix / Growth-Share Matrix | Matriz de portafolio que cruza crecimiento de mercado y cuota relativa (estrella/vaca lechera/interrogante/perro). |
| ERRC | Eliminar, Reducir, Incrementar, Crear | Eliminate, Reduce, Raise, Create | Marco de las cuatro acciones de Blue Ocean Strategy para rediseñar una curva de valor. |
| JTBD | Trabajos por Hacer | Jobs to be Done | Marco que define la competencia y la oportunidad de innovación por el "progreso" que el cliente busca, no por categoría de producto. |
| BSC | Cuadro de Mando Integral | Balanced Scorecard | Sistema de medición de desempeño en 4 perspectivas (financiera, cliente, procesos internos, aprendizaje y crecimiento). |
| CAC / LTV | Coste de Adquisición de Cliente / Valor de Vida del Cliente | Customer Acquisition Cost / Lifetime Value | Métricas de unit economics: cuánto cuesta adquirir un cliente y cuánto ingreso neto genera a lo largo de su relación. |
| NPV / VAN | Valor Actual Neto | Net Present Value | Valor de un flujo de caja futuro descontado a euros de hoy, menos la inversión inicial. |

## Checklist de calidad pre-entrega

Antes de entregar cualquier informe de esta skill, repasa:

- [ ] Se etiquetó explícitamente el análisis como Estratégico o Táctico, con su horizonte temporal.
- [ ] No se aplicaron más de 2-3 frameworks salvo que el usuario pidiera expresamente un análisis completo.
- [ ] Las recomendaciones priorizadas tienen Impacto y Esfuerzo asignados, no solo una lista sin orden.
- [ ] Se ofreció (no se forzó) el módulo de narrativa estratégica al final del informe.
- [ ] Si la petición era de marca/naming/posicionamiento de marca pura, se redirigió a `brand-strategy` o `brand-positioning` en vez de forzar DAFO/PESTEL.
- [ ] Las preguntas de contexto (negocio, objetivo, horizonte, alcance) se hicieron una sola vez y no se repitieron datos que el usuario ya había dado.

## Anti-patrones habituales

- **Aplicar DAFO como checklist mecánico en vez de como insumo para una decisión
  real.** Rellenar cuatro cuadrantes sin conectarlos con una recomendación
  convierte el framework en papeleo, no en estrategia.
- **Confundir "urgente" con "estratégico".** Mezclar horizonte temporal sin
  darse cuenta lleva a tratar un problema táctico de corto plazo con el peso y
  la formalidad de una decisión de largo plazo (o viceversa), y descoloca las
  recomendaciones.
- **Aplicar McKinsey 7S sin haber definido antes la estrategia que esas 7S
  deben soportar.** El 7S diagnostica alineamiento interno *alrededor* de una
  estrategia ya elegida; usarlo primero deja sin referencia contra la que
  comparar estructura, sistemas o cultura.
- **Ofrecer narrativa estratégica antes de tener un análisis sólido detrás.**
  Contar bien una historia sin una decisión fundamentada solo produce un
  relato convincente sobre una estrategia que todavía no existe.
- **Tratar VUCA y BANI como intercambiables.** VUCA mira hacia fuera (el
  mercado y el entorno son impredecibles); BANI mira hacia dentro (las
  personas y la organización sienten fragilidad, ansiedad y falta de sentido
  ante ese mismo entorno). Usar uno por el otro difumina si el problema es de
  mercado o de organización.
